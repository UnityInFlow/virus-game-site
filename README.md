# virus-game-site

The public face of [Virus Game](https://github.com/UnityInFlow/virus-game): the map,
the leaderboard and the tick history.

**Everything under `data/` is generated.** It is written by the tick job in the game
repository after every successful tick and pushed here. Do not edit it, and do not open
pull requests against it. The game engine, the rules and the player strains live in the
game repository, which is private.

The page itself (`index.html`, `app.js`, `style.css`) is built in STORY-0502 and is a
placeholder until then.
